# Mumbai ParkView
Mumbai ParkView is an interactive web mapping project built with Python and Folium that visualizes parks, gardens, and regional district boundaries across the Mumbai Metropolitan Region (MMR).

# Features
Dynamic Park Clustering: Renders the Parks/Gardens from GeoJSON data using folium marker clusters for high-performance navigation without UI lag.

Custom Info Popups: Interactive popups displaying detailed data for each park/garden.
